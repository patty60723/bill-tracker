# 繳費小幫手(bill-tracker)

記錄每月繳費的手機網頁 app(PWA,可「加到主畫面」當成 app 用):掃描繳費單、記錄每期金額與
截止日、上傳繳費證明、固定繳費的拿單與截止提醒。資料只存在手機裡,不上傳任何伺服器。

實作細節與演算法見 [`docs/TECHNICAL.md`](docs/TECHNICAL.md)。

## 功能

### 掃描繳費單

新增帳單頁有三種方式,可以混用:

| | 做法 | 適合 |
|---|---|---|
| 📷 **拍照辨識** | 開相機拍整張繳費單 | 一般情況 |
| 🖼️ **從相簿選** | 先用手機相機 App 拍好再選 | 想要最好的畫質(對焦、HDR) |
| ▦ **對準條碼掃** | 即時相機,鏡頭靠近條碼,一條一條掃也可以 | 整張照片裡條碼太小、太糊讀不到時 |

- **條碼**:台灣超商代收的三段式條碼(第一段 = 代收期限、第三段 = 應繳金額),民國、西元年都認得。
- **稅單**:讀「全國繳稅網」QR Code,直接帶入繳款類別、銷帳編號、金額、繳納截止日。稅單上的
  「繳納截止日」是繳納期間屆滿後 3 日,所以截止日自動往前算 3 天(遇假日展延也正確),
  條碼上的日期寫進備註。
- **文字辨識(OCR,繁中 + 英文)**:找「應繳金額」「繳款截止日」「繳費帳號」「銷帳編號」等,
  也認得「115 年 09-10 月」→ 9 月、雙月。辨識前先做文件影像增強(去陰影、去色塊底、拉對比)。
- 都找不到「期限」字樣時,用帳單上近期最晚的日期**推測**截止日並標示「推測」。
- 掃描結果下方的「**辨識細節**」列出各步驟耗時、照片解析度、讀到的條碼(含三段式條碼各段有沒有讀到、每個條碼是哪個引擎讀到的、各引擎的次數與耗時)與文字、錯誤訊息,有「📋 複製辨識細節」按鈕;照片解析度偏低會提醒。
- 條碼讀到一段、另外幾段沒讀到時,會把那一欄放大重掃;條碼都沒讀到,也會用文字辨識讀到的「條碼下方數字」補截止日。
- 台電等帳單:條碼日期是「代收截止日」時,截止日改用帳單上的「繳費期限」,代收截止日寫進備註。
- 文字辨識前會說明原因:沒讀到條碼、條碼只讀到一部分,或條碼已齊全、只是要找帳單上的繳費帳號。
- 同一個畫面掃第二張時,會問是「另一張帳單」(清掉上一張帶入的資料與照片)還是
  「同一張的另一頁」(合併)。
- 帶入的結果一律要自己核對再存。

### 帳單與固定繳費

- **每期帳單**:名稱、類別、帳單月份、帳單週期(單月/雙月/每季/半年/每年)、金額、截止日、
  繳費帳號、是否已繳、繳費日期與方式、備註。
- **繳費帳號 / 銷帳編號**:轉帳用「銀行代碼 + 帳號」,繳稅用「繳款類別 + 銷帳編號」。
  帳單頁與首頁提醒都有 📋 一鍵複製。
- **照片與繳費證明**:繳費單照片、收據/轉帳截圖/PDF。
- **固定繳費**:週期、帳單大約幾號到、幾號截止(比到單日早 = 隔月截止;「月底」自動對應天數)、
  截止前幾天提醒、預設帳號。新增帳單時勾「同時存成固定繳費」可一次建好。
  固定繳費頁下方列出這個項目每一期的帳單。
- **自動扣款**:固定繳費勾「自動扣款」後,到截止日自動記成「已繳(自動扣繳)」,不再提醒拿單、繳費;
  已經登記但未繳的那期也會在扣款日自動標成已繳。只處理開啟之後截止的期別,刪掉自動建立的紀錄也不會再冒出來。
- **標記已繳**:列表與首頁一鍵標記,接著可以直接「📷 拍照上傳」或「🖼️ 選照片或 PDF」上傳繳費證明,
  也可以「之後再說」或「復原」。
- **紀錄**:依月份瀏覽(總額/已繳/未繳)或切到「所有帳單」看全部月份,可篩選未繳/已繳。
- **搜尋**:紀錄頁上方的搜尋框,可以用名稱、金額(`1286` 或 `1,286`)、帳號、備註、類別、月份(`2026-10`)找,
  多個關鍵字用空白隔開;結果跨所有月份並顯示合計。
- **統計**:紀錄頁的「統計」分頁:全年總額、已繳、月平均,跟去年**同期**比較(今年還沒過完時只比 1 月到本月);
  12 個月長條圖(點長條看當月明細);各類別金額、占比與跟去年比較。
- **匯出 CSV**:統計頁可匯出單一年度或全部帳單,設定頁也可以匯出全部;Excel 直接開不會亂碼,
  長帳號不會變成科學記號。
- 表單有沒儲存的變更時,離開(返回、切分頁、手機返回鍵)會先確認。

### 提醒

- **首頁待辦**:到單前 3 天預告 → 該去拿繳費單 → 快截止(紅色)→ 逾期 / 這期沒登記。
  自動扣款的項目只顯示「M/D 自動扣款」,不催繳。
- **手機通知**:有快截止、逾期、該拿單的帳單就通知(同一天同樣內容不重複)。
  - Android Chrome + 「加到主畫面/安裝應用程式」:**沒開 app 也會通知**(瀏覽器大約一天叫醒一次,
    時間由瀏覽器決定,只在 8:00–22:00 跳)。
  - 其他瀏覽器、iPhone:只有打開 app 時通知。
  - 設定頁「現在測試一次通知」會當場檢查權限、送出並確認有沒有顯示,失敗時說明要去哪裡打開。
- **加到手機行事曆(.ics)**:到單日早上 9 點、截止前 N 天、截止當天準時提醒,iPhone 也適用。
  改了設定再匯出一次即可(同一項目會更新,不會重複)。

### 新手引導

第一次打開時首頁顯示三個步驟,完成的自動打勾:加到主畫面(Android Chrome 可直接按「安裝 app」,
iPhone 顯示 Safari 加入主畫面的步驟)→ 開啟通知 → 建立第一個固定繳費或掃第一張帳單。
可以按「不用了」關掉,之後在「設定 → 新手引導」再打開。

### 備份

網頁 app 不能在背景自己存檔或上傳,所以採「**該備份時提醒 + 一鍵存到雲端**」:

- **提醒**:從沒備份過且已用了 3 天、距上次備份超過 30 天且之後有變更、或一週內改了 20 筆以上時,
  首頁出現「💾 該備份了」卡片(可「7 天後再提醒」),手機通知也會提醒(每月最多一次)。
- **立即備份**:開手機的分享選單,選「雲端硬碟」或用 Gmail / LINE 傳給自己;不支援分享時改成下載。
  備份檔是一個 JSON(分享時可能是 `.txt`),包含所有帳單、固定繳費與照片。
- **設定頁**顯示上次備份時間與之後的變更筆數。
- **匯入備份**:先顯示備份時間與內容(幾筆帳單、固定繳費、檔案)再確認;換手機時在新手機匯入即可。
- 「保護資料」:要求瀏覽器不要在空間不足時自動清掉這個 app 的資料。

## 資料存在哪

全部存在手機瀏覽器的 IndexedDB,**不會上傳到任何伺服器**。代價是清除瀏覽器資料、換手機就會不見,
所以 app 會在該備份時提醒你,用分享選單把備份檔存到雲端硬碟。

## 安裝與執行

純靜態網頁,不用 build:

```bash
python3 -m http.server 8000   # 打開 http://localhost:8000/

npm install                   # 只有開發工具(Playwright、ESLint),app 本身沒有相依套件
npm run lint                  # ESLint(未定義 / 未使用變數等)
npm test                      # 單元測試(node:test)
npx playwright install chromium   # 第一次跑端對端測試前
npm run test:e2e              # 端對端測試(真的開瀏覽器操作 app)
npm run test:all              # 全部
```

GitHub Actions(`.github/workflows/test.yml`)在每次 push / PR 自動跑 lint、單元與端對端測試。

- 手機上要用相機、通知、「加到主畫面」,網址必須是 **HTTPS**:把整個 repo 放到 GitHub Pages
  (Settings → Pages → `main` / root)、Netlify、Cloudflare Pages 等靜態空間即可。
- **Android**:用 Chrome 開啟 → 選單「加到主畫面 / 安裝應用程式」→ 從主畫面圖示開啟,背景通知才會運作。
  換了圖示或 manifest 後,建議移除再重新安裝一次。
- **iPhone**:用 Safari 開啟 →「分享 → 加入主畫面」,通知功能才會出現(只有開著 app 時通知)。
- 更新:部署後把 app 完全關掉再開,約兩次就會載入新版(service worker 會換掉舊快取)。

## 已知限制

- 條碼格式各家不同(郵局劃撥、部分銀行/電信不是三段式),讀不到的就靠 OCR 或手動填。
- OCR 在拍歪、反光、字很小時容易看錯,所以只用來預填。目前只用 2 張真實帳單驗證過。
- 網頁 app 不能指定「幾點幾分」通知;背景通知只有 Android Chrome 支援。要準時或在 iPhone 上提醒,
  請用匯出的行事曆。
- 從手機多工畫面直接滑掉 app 時,沒儲存的表單攔不住。
