# 繳費小幫手(bill-tracker)

記錄每月繳費的手機網頁 app(PWA,可「加入主畫面」當成 app 用)。

## 功能

- **掃描繳費單**:拍照後自動讀條碼,帶入金額與截止日。台灣超商代收的「三段式條碼」
  (第一段 = 代收期限,第三段 = 應繳金額)讀得最準;條碼不完整時會改用文字辨識
  (OCR,繁中+英文)找「應繳金額」「繳費期限」之類的字。帶入結果一律要自己核對。
- **每期帳單紀錄**:金額、帳單月份、截止日、是否已繳、繳費日期與方式、備註。
- **照片與繳費證明**:繳費單照片、收據/轉帳截圖/PDF 都可以存(照片會自動壓縮)。
- **固定繳費**:設定週期(每月/雙月/每季/半年/每年)、帳單大約幾號到、幾號截止
  (截止日比到單日早 = 隔月截止;「月底」會自動對應每月天數)、截止前幾天提醒。
- **提醒**
  - 首頁「待辦提醒」:到單前 3 天預告 → 該去拿繳費單 → 快截止(紅色)→ 逾期/這期沒登記。
  - **匯出 .ics 加到手機行事曆**(最推薦):到單日早上 9 點、截止前 N 天、截止當天會跳提醒,
    不用開 app。改了設定後再匯出一次即可,同一項目會更新而不是重複。
  - 開 app 時的系統通知(每天一次,需允許通知)。
- **月統計**:總額、已繳、未繳;可以按月份翻、篩選未繳/已繳。
- **備份**:匯出/匯入 JSON(含照片)。

## 資料存在哪

全部存在手機瀏覽器的 IndexedDB,**不會上傳到任何伺服器**。代價是:清除瀏覽器資料、
換手機就會不見,所以請定期在「設定 → 匯出備份」。設定頁的「保護資料」可以降低瀏覽器
在空間不足時自動清掉資料的機會。

## 執行

純靜態網頁,不用 build:

```bash
python3 -m http.server 8000   # 打開 http://localhost:8000/
npm test                      # 單元測試(條碼/OCR 解析、週期、提醒、ics)
```

手機上要用相機、通知、「加入主畫面」,網址必須是 **HTTPS**。最簡單的做法是把
整個 repo 放到 GitHub Pages / Netlify / Cloudflare Pages 這類靜態網站空間。
iPhone 請用 Safari 開啟後「分享 → 加入主畫面」,通知功能才會出現。

## 檔案

| 檔案 | 內容 |
|---|---|
| `src/app.js` | 畫面與路由(首頁、紀錄、帳單編輯、固定繳費、設定) |
| `src/parse.js` | 條碼與 OCR 文字 → 金額/截止日 |
| `src/schedule.js` | 固定繳費週期計算、提醒清單、月統計 |
| `src/ics.js` | 匯出行事曆提醒 |
| `src/scan.js` | 讀條碼(zxing-wasm,離線)、OCR(Tesseract.js,第一次需網路下載約 10–20 MB) |
| `src/db.js` | IndexedDB 存取、備份 |
| `vendor/` | [zxing-wasm](https://github.com/Sec-ant/zxing-wasm) 2.2.4 reader(MIT),讓條碼掃描離線可用 |

## 已知限制

- 條碼格式各家不同(郵局劃撥、銀行、電信帳單可能不是三段式),讀不到的就靠 OCR 或手動填。
- OCR 在拍歪、反光、字很小時容易看錯,所以只用來預填。
- 網頁 app 不能在背景自己排程通知,所以「不開 app 也會提醒」要靠匯出的行事曆。
