# Gmail 帳單收件匣(Google Apps Script)

讓 Gmail 裡的電子帳單自動進到「繳費小幫手」:

```
Gmail(標籤「帳單」)→ 你自己 Google 帳號裡的這支 Apps Script → app(背景同步 / 打開 app 時取件)
```

- 程式只在**你自己的 Google 帳號**裡執行,不經過任何第三方伺服器。
- 權限只要「**唯讀** Gmail」(`appsscript.json` 限制的),不能寄信、不能刪信。
- app 用「網址 + 金鑰」取件。**網址和金鑰不要給別人**:拿到的人可以下載你的帳單 PDF。

大約 10 分鐘,用電腦設定比較方便。

## 1. Gmail:幫電子帳單加上「帳單」標籤

1. Gmail 左邊「建立新標籤」→ 名稱 `帳單`。
2. 搜尋列右邊的「顯示搜尋選項」,填寄件者(例如台灣大哥大、台電、信用卡的電子帳單寄件地址,
   多個用 `OR` 隔開),勾「含有附件」→「建立篩選器」→ 勾「套用標籤:帳單」,
   也可以勾「同時將篩選器套用至相符的會話群組」把舊信一起標上 →「建立篩選器」。

之後只要信件有「帳單」標籤、附件是 PDF(或圖片),就會出現在 app 的收件匣。

## 2. 建立 Apps Script

1. 打開 <https://script.google.com> →「新專案」,專案名稱改成 `繳費小幫手收件匣`。
2. 把 `程式碼.gs` 的內容全部換成這個資料夾的 [`Code.gs`](Code.gs),按儲存。
3. 左邊齒輪「專案設定」→ 勾「在編輯器中顯示『appsscript.json』資訊清單檔案」,
   回到編輯器打開 `appsscript.json`,內容換成這個資料夾的 [`appsscript.json`](appsscript.json),儲存。
4. 上方函式選單選 `setup` →「執行」。第一次會要求授權:
   - 選你的 Google 帳號 → 出現「Google 尚未驗證這個應用程式」(因為是你自己寫的,沒有送審)
     →「進階」→「前往 繳費小幫手收件匣(不安全)」→ 確認權限只有「查看你的電子郵件訊息和設定」→「允許」。
5. 下方「執行記錄」會印出 **金鑰**,先複製起來。

## 3. 部署成網頁應用程式

1. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」。
2. 執行身分:**我**;誰可以存取:**所有人**(app 沒有登入 Google,靠金鑰驗證)→「部署」。
3. 複製「網頁應用程式」網址(`https://script.google.com/macros/s/…/exec`),在後面加上 `?key=` 和剛剛的金鑰:
   `https://script.google.com/macros/s/……/exec?key=你的金鑰`

## 4. app 設定

1. 打開繳費小幫手 →「設定」→「📬 Gmail 帳單收件匣」,貼上完整網址 →「儲存並測試」。
   看到「✅ 連上了:Gmail 標籤「帳單」裡有 N 張待記錄」就好了。
2. 「有把握的自動記錄」預設打開:認得是哪個固定繳費、條碼或 PDF 文字讀得到金額和截止日、沒有警告的,
   會直接存;其他的停下來讓你確認。**第一次收到某家的帳單時會停下來**,存成固定繳費之後,下一期就會自動記錄。
3. 有密碼的 PDF:第一次在密碼框勾「記住這個密碼」,之後背景下載、自動記錄時就不用再輸入。

## 背景同步

Android 上把 app「加到主畫面」並開啟通知後,瀏覽器會定期叫醒 app(多久一次由 Chrome 決定,大約一天幾次):
先把新的電子帳單下載好,跳通知「📬 收到 N 張電子帳單」,點通知就到收件匣。
打開 app 時也會立刻取一次。

## 之後要改

- **改程式**:貼上新的 `Code.gs` 後,「部署 → 管理部署作業 → 編輯(鉛筆)→ 版本:新版本 → 部署」,網址不變。
- **換金鑰**(網址外流時):「專案設定 → 指令碼屬性」刪掉 `KEY`,再執行一次 `setup`,app 設定頁貼上新的網址。
- **改標籤名稱或天數**:改 `Code.gs` 最上面的 `LABEL`、`DAYS`。
- **停用**:「部署 → 管理部署作業 → 封存」,app 設定頁按「取消設定」。
